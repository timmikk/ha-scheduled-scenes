# Plan

Create or update a component-scoped task in `tasks/`. First inspect the
relevant code, tests, README, and existing tasks. Keep the plan focused on the
user's outcome, name affected files and concrete validation, and capture
dependencies and security implications. Use the next sequential task number
consistent with this repo. Cross-cutting deployment, infrastructure, or HACS
pipeline work belongs in `~/dev/infra/tasks/`. Regenerate `TODO.md` with
`node ~/dev/dev-tools/scripts/todo-status.mjs --write` when task metadata
changes.
