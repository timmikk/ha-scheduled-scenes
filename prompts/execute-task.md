# Execute Task

Read `AGENTS.md` and the selected task in `tasks/` completely. Implement its
scope and acceptance criteria, preserve unrelated work, and record progress,
decisions, and validation evidence in the task file. Keep component changes in
this repo; send deployment, infrastructure, or HACS pipeline work to the infra
planning hub. Run the checks required by the task and project docs for changed
code. Do not mark the task done until its definition of done is met. Then move
the task to `tasks/done/`, update its status and completion record, and
regenerate `TODO.md`.
