# ha-scheduled-scenes

Dynamic scheduled scenes and circadian lighting for Home Assistant

Home Assistant integration installed via HACS from
[timmikk/ha-scheduled-scenes](https://github.com/timmikk/ha-scheduled-scenes) (public
GitHub mirror of the Forgejo primary at
[git.clo.dy.fi/timo/ha-scheduled-scenes](https://git.clo.dy.fi/timo/ha-scheduled-scenes)).

## Install

1. HACS → ⋮ → Custom repositories, add
   `https://github.com/timmikk/ha-scheduled-scenes`, category **Integration**.
2. HACS → Explore, find "Dynamic scheduled scenes and circadian lighting for Home Assistant", Download.
3. Restart Home Assistant.
4. Settings → Devices & Services → Add Integration → Dynamic scheduled scenes and circadian lighting for Home Assistant.

## Rollback

HACS → this integration → Redownload → pick prior version → restart HA.
